# Dalmia Cement Ariyalur — Kiln Efficiency & Deposit Build-Up POC

## Objective

Move from reactive detection of kiln inefficiency and deposit build-up toward planned intervention:

```text
Reactive Detection
→ Early Detection
→ Prediction
→ Planned Intervention
```
