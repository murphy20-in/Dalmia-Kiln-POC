
| File | Content |
|---|---|
| `source_manifest.csv` | One row per source workbook: path, equipment folder, filename month vs months actually in the data, first/last timestamp, data rows, header/unit/data-start rows, sheet name, size, SHA-256, `status` (`USE` / `EXCLUDE_UNREADABLE` / `EXCLUDE_DUPLICATE_CONTENT`), notes |
| `dataset_registry.csv` | One row per expected equipment dataset: availability, readable files, rows, date range, missing months, parameter count, process families, sheet title |

Both files are generated by `phase-01-data-discovery/scripts/export_data_manifest.py` (run as part of `run_phase1.py`) from the Phase 1 outputs.

Readers should check the SHA-256 in `source_manifest.csv` before trusting a source file. A mismatch means the source changed after Phase 1 and needs a re-run.
