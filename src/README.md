# Source Code

Shared source code modules for the Dalmia Kiln POC project.

## Modules

- `ingestion/` - Data ingestion and loading
- `preprocessing/` - Data cleaning and transformation
- `features/` - Feature engineering
- `baseline/` - Baseline computation
- `efficiency/` - Efficiency KPI calculations
- `indicators/` - Leading indicator computation
- `anomaly/` - Anomaly detection
- `risk/` - Risk scoring
- `prediction/` - Predictive models
- `explainability/` - Model explainability
